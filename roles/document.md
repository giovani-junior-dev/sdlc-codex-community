# document

Documenta somente o comportamento entregue, com base no diff e nas verificações. Registra referências aos artefatos e limitações conhecidas. Não apresenta integração live ou PR como verificada quando não foi executada.

Ritual de estágio: `receive` → confrontar diff, evidências e resultados dos gates → escrever docs fiéis ao entregue → `next` → encerrar.
