Requisitos para instalar o SDLC Codex.

O SDLC Codex coordena ferramentas instaladas no seu computador. Instale os componentes abaixo e depois confira o ambiente no terminal.

Já tenho os requisitos ↓

Node.js + npm

Node.js 22 ou superior

Executa e instala o CLI do SDLC Codex. Escolha o instalador para Windows com npm e reabra o terminal após instalar.

Herdr ↗

Terminal do time

Organiza as sessões Codex em abas e painéis. É necessário para abrir o time com sdlc-codex up; o SDLC Codex não instala o Herdr automaticamente.

Instalar Herdr ↗ (abre em nova aba)
Como instalar e abrir o Herdr no Windows?+
  1. Abra o guia oficial de instalação (nova aba) e siga a opção Windows.
  2. Se preferir o download manual, vá às releases oficiais (nova aba) e baixe herdr-windows-x86_64.zip. Extraia a pasta inteira: mantenha herdr.exe e os arquivos de runtime juntos.
  3. No download manual, adicione a pasta extraída ao PATH do usuário. Reabra o terminal para carregar o novo PATH.
  4. Execute herdr --version para conferir a instalação e herdr para abrir o aplicativo no terminal.

O SDLC Codex foi validado com Herdr 0.7.5-preview. A versão atual oferecida pelo instalador pode ser diferente: confira a compatibilidade com doctor antes de abrir o time.

Quais acessos e versões preciso conferir?+

A base validada do projeto usa Windows nativo, Node.js 22, Codex CLI 0.155.1 e Herdr 0.7.5-preview. Isso não garante compatibilidade automática com toda versão posterior. Veja o registro de compatibilidade.

Para baixar o SDLC Codex, o código e os downloads estão disponíveis publicamente. Para fluxos feature e hotfix, o projeto atendido precisa de um remoto GitHub e de permissão para publicar a branch e abrir PR. O Codex precisa estar autenticado com acesso ao modelo que será usado.

Algo não funcionou na instalação?+
  • Comando não encontrado: reabra o terminal e confira o PATH. Para o SDLC Codex, consulte npm prefix --global e confira se essa pasta está no PATH.
  • PowerShell bloqueou o shim .ps1: tente sdlc-codex.cmd --help ou npm.cmd, sem alterar a política global.
  • GitHub retornou 404 ou acesso negado: confira gh auth status e o acesso ao repositório público.
  • queue, hooks ou Herdr incompatíveis: confira as versões no registro de compatibilidade. Depois de instalar o SDLC Codex, use sdlc-codex doctor --project . --json.
  • doctor apontou configuração ausente: em um projeto ainda não adotado, prepare o arquivo de configuração na etapa 03. Resolva também os erros de ferramentas antes de abrir o time.

O que é o SDLC Codex e para quem ele serve?+

O SDLC Codex Community é um CLI open source para desenvolvedores e estudantes que querem coordenar agentes de programação em sessões independentes do Codex. Ele usa o Herdr para organizar cinco papéis: planner, dev, reviewer, tester-e2e e document, com mensagens bidirecionais, estado persistido e evidências de entrega.

Como instalar e começar a usar no Windows?+

Instale Node.js 22+, Git, GitHub CLI, Codex CLI e Herdr. Autentique as ferramentas, baixe o pacote da release v0.1.0 e instale com npm install --global .\sdlc-codex-0.1.0.tgz. Confira sdlc-codex --help e siga o tutorial com comandos e prompts para preparar o projeto e abrir o time.

O SDLC Codex é gratuito? Posso usar nas aulas?+

O código do SDLC Codex Community está disponível sob licença MIT. Você pode usar, modificar e redistribuir o projeto, preservando o aviso de copyright e a licença. O acesso aos modelos do Codex e a serviços externos depende das condições e dos custos dos respectivos fornecedores.

É um painel web para controlar meus agentes?+

O SDLC Codex é um CLI local. Ele organiza sessões independentes do Codex no Herdr. Esta página apresenta o projeto e ensina a usá-lo; não monitora nem executa suas sessões.

Posso pedir ao próprio Codex para preparar o projeto?+

Sim. No tutorial, escolha “Prompt para o Codex”. O agente verifica o ambiente, prepara a configuração e abre o time. A execução da demanda depende do plano e dos artefatos de aprovação exigidos pelo método.

O time faz merge ou deploy automaticamente?+

Não. O fluxo feature passa por desenvolvimento, revisão, testes, PR, revisão da PR e documentação. Merge, deploy e mudanças fora do escopo continuam sob decisão humana.

Já posso usar DeepSeek, GLM ou outros provedores?+

A primeira versão usa os modelos disponíveis na sua instalação do Codex. A compatibilidade com provedores externos ainda está em pesquisa e não foi demonstrada.
